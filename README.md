# Fold — Rust-порт программы 2007 года

[![Build](https://github.com/AmazingCoderA/fold-rs/actions/workflows/build.yml/badge.svg)](https://github.com/AmazingCoderA/fold-rs/actions/workflows/build.yml)

Полный независимый порт программы **Fold — «Построение структурной карты отражающего горизонта»** (Viktor Romanov, 2007), написанной на Delphi/VCL и упакованной ASPack.

**Цель:** один в один повторить интерфейс и логику, но считать быстрее оригинала и работать там, где его нет: Windows, Linux, macOS, Android.

## GUI 1:1

Интерфейс восстановлен по предоставленному скриншоту (894×656):

```
┌─────────────────────────────────────────────────────────────┐
│ [Структура] [Профили] [Стереть] [Строка] ... [Цвет] [Справка]    │
├────────────────┬────────────────────────────────────────────┤
│ Параметры      │  Построение структурной карты ...           │
│ структуры      │  Структурная карта              X, м        │
│ V ср 1200      │ ┌────────────────────────────────────────┐ │
│ f 10           │ │        цветная карта + сетка           │ │
│                │ │  профили рисуются мышью               │ │
│ Координаты     │ └────────────────────────────────────────┘ │
│ профиля        │  Временной разрез  Hmin[21 полоса]Hmax    │
│ Профиль №      │ ┌────────────────────────────────────────┐ │
│ X 3100 Y 100   │ │ t,с  виггл-трассы, пики кликом, 1..10   │ │
│                │ └────────────────────────────────────────┘ │
│ Таблица        │             Rust version Fold by Lion 2026│
│ корреляции     │                                            │
│ t0 = 3.465 с   │                                            │
│ [Назад][Далее] │                                            │
│ [Стереть]      │                                            │
│ Качество       │                                            │
└────────────────┴────────────────────────────────────────────┘
```

- палитра карты и легенда — одна и та же 21-полосная шкала из скриншота (синий → голубой → зелёный → жёлтый → красный), координаты легенды x=440..653, y=436..453, подписи H min / H max по бокам;
- **Цвет** переключает 5 палитр: Классика (точь-в-точь original), Океан, Пламя, Лайм, Графит;
- V ср по умолчанию 1200 м/с, качество 95, координаты профиля 3100 / 100 — как на скриншоте;
- поля ввода левой панели получили утопленную обводку и видимый фокус. **Tab / Shift+Tab** обходит V ср → f → X → Y;
- кнопки — обычные нативные виджеты с фиксированным цветом и тонкой рамкой: больше нет градиентных швов-артефактов при масштабировании. **Структура** — «О программе», **Профили** — переключение, **Стереть таблицу** — очистка пиков, **Назад / Далее** — листание профилей, **Справка** — подсказка;
- **Строка** открывает окно ввода/вывода готовой строки: «Скопировать» кладёт текущее состояние в буфер, вставленная строка + «Применить» восстанавливает все профили и настройки;
- сетка исправлена по пиксельному разбору: карта — 8 вертикальных и **10 горизонтальных** делений (шаг 35 px), временной разрез — **10 делений** по времени с подписями 3.20…3.60 с;
- профиль добавляется перетаскиванием мыши по карте, пик — кликом по «Временному разрезу». Внизу — пухлые **залитые чёрные виггл-лепестки** (амплитуда ~20 px, Ricker-вейвлет 18 Гц), как в original: замер по пикселям показал главный лепесток x=563..583, y=501..519;
- таблица корреляции — сетка x=34..150 с шагом строки 12 px. У каждой строки есть крестик **×** справа: удаляет именно эту запись, не всю таблицу;
- пересчёт и загрузка текстуры происходят только при смене угла/размеров карты/палитры. Палитра считает min/max один раз за проход, текстура переиспользуется — в idle кадры не теряются.

## Сборка и запуск

### Desktop

```powershell
cargo build --release
.\target\release\fold.exe examples\demo.txt map.pgm   # CLI
.\target\release\fold-gui.exe                         # GUI
.\target\release\fold.exe --bench                     # бенчмарк
cargo test --release
```

На Linux для GUI нужны:
```bash
sudo apt install pkg-config libx11-dev libxi-dev libgl1-mesa-dev libudev-dev libxkbcommon-dev libwayland-dev
cargo build --release
```

### Android

Нативный код считает карту, Kotlin-интерфейс рисует её и обрабатывает касания:

```bash
cargo install cargo-ndk
cargo ndk --manifest-path android-rs/Cargo.toml \
  -t arm64-v8a -t armeabi-v7a -t x86_64 \
  -o android/app/src/main/jniLibs build --release
gradle -p android assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/`. В CI это делает job `android`; готовый `fold-android-universal.apk` прикрепляется к каждому релизу вместе с `SHA256SUMS.txt`.

### AUR (Arch Linux)

```bash
yay -S fold-rs-git
# или локально:
cd packaging/aur && makepkg -si
```

Инструкция по публикации пакета — `packaging/aur/README.md`.

```
v 1500        # средняя скорость, м/с
q 95          # качество, %
profile x0 y0 x1 y1
pick трасса время
...
end
```

`#` — комментарий. Пример: `examples/demo.txt`.

## Производительность

| Что меряли | Время |
|---|---|
| Старт оригинального `03_Fold.exe` | ~370 мс |
| Rust, 15 профилей × 200 пиков | **2.1 мс** |
| Rust, демо | ~0.4 мс |

Алгоритм: `H = V·t/2`, шаг 200 м, карта 8000×4000 м, веса 0.4/0.6, радиус 2000 м — константы вытащены из распакованного бинарника.

## Структура

- `src/model.rs`, `src/velocity.rs`, `src/grid.rs` — ядро;
- `src/io.rs` — парсер и PGM-вывод;
- `src/gui.rs` — egui-клон формы;
- `android-rs/` — JNI-мост на Rust;
- `android/` — Gradle/Kotlin приложение;
- `.github/workflows/` — CI и релизы;
- `packaging/aur/` — PKGBUILD;
- `analysis/` — скрипты дампа, DFM-парсер, дизассемблер и отчёты.

## Оговорка

Нелинейный фильтр оригинала (`0x466250` / `0x466980`) восстановлен приближённо по константам и FPU-коду. Геометрия, единицы и интерфейс сохранены; при эталонных картах корректируется весовая функция в `src/grid.rs`.

Оригинал — забытый эксперимент 2007 года: **лицензий и обещаний нет**.
